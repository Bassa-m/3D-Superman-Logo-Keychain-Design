## 📝 Project Description
This repository contains the 3D design file for a Superman logo keychain. The model was designed and created using **Onshape** CAD software. ⚙️

## 🛠️ Workflow and Execution Steps:

### 1. 🖼️ Reference Image Insertion & Scaling (Tracing)
* Selected a high-quality reference image of the Superman logo.
* Created a new **Sketch** on the **Front Plane**.
* Inserted the image using the **Insert Image** tool and scaled the overall width of the logo to approximately **50 mm** to ensure it is appropriately sized for a functional keychain. 📏

### 2. ✏️ Sketching & Tracing the Logo
* Used the **Line** tool to accurately draw the outer pentagonal shield.
* Used the **Spline** tool to trace the precise inner curves of the letter **S**.
* Ensured all geometric shapes were fully closed to create solid regions for extrusion. ✔️

### 3. 🔑 Adding the Keychain Hole
* Selected a strategic and strong area at the top of the shield to ensure durability and prevent the keychain from breaking during daily use. 🛡️
* Sketched a circle using the **Center Point Circle** tool and defined its diameter precisely as **4 mm** using the **Dimension** tool, as required by the task instructions. 🎯

### 4. 🧊 3D Extrusion
* Applied the **Extrude** tool to the targeted regions (the outer shield frame and the letter S).
* Set the extrusion **Depth** to exactly **2 mm** according to the required specifications.
* Excluded the 4 mm circular hole and the negative spaces inside the logo from the selection to keep them hollow in the final 3D body. 🧱

### 5. 💾 STL Export
* After finalizing the 3D model and verifying its dimensions, the part was exported from the **Parts** list.
* Selected the **Export** command and applied the following settings:
  * **Format:** STL
  * **Units:** Millimeter
  * **Resolution:** Fine (to ensure smooth edges and high-quality details for 3D printing). 🖨️
